# Frontend

React 19 + TypeScript + Vite. Ver el [README principal](../README.md).

```bash
npm run dev      # servidor de desarrollo (http://localhost:5173)
npm run build    # type-check + build de producción
npm run lint     # oxlint
```

Imports con alias `@/` → `src/`. Cada feature expone su API pública en `features/<feature>/index.ts`.
